# 0004 — The issue body is the contract

**Status:** Accepted, 2026-11-18

## Decision

Every ticket has `## Current thinking`, `## Acceptance` (checkable items) and `## Blockers`. If a decision only exists in chat, it doesn't exist. The builder refuses to plan when the acceptance list is missing or a blocker is open, and the reviewer grades every acceptance item with evidence.

## Consequences

Writing tickets takes more effort up front. In exchange, every reviewer grades against the same thing, and missing context shows up before it turns into code.
